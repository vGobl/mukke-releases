# Mukke releases

Installers for **Mukke**, a desktop app for your own music library: import your folders,
clean up metadata, and listen offline. This repository holds only the release files;
the source code is private.

## Install

Download the newest release from **[Releases](../../releases/latest)**.

**Windows**
1. Download `Mukke-Setup-<version>.exe` and run it. No admin rights needed; Mukke
   installs for your user and adds a Start menu and desktop shortcut.
2. Windows may show "Windows protected your PC", because the test builds are not
   code-signed yet. Click **More info**, then **Run anyway**.

**macOS**
1. Download `Mukke-<version>-arm64.dmg`, open it and drag Mukke into Applications.

## Updates

- **Windows:** Mukke checks for updates by itself and downloads them in the background.
  When one is ready it asks you to restart; choose **Later** and it installs the next
  time you quit Mukke.
- **macOS:** Mukke tells you when a new version is out and opens its download page.
  Install it over the old app.

Your libraries and settings stay as they are when you update.
